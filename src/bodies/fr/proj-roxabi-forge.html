PLUGIN CLAUDE CODE · ARTEFACTS VISUELS

roxabi-forge

Un plugin Claude Code qui transforme « explique-moi ça » en une image que tu peux livrer. Huit skills produisent des artefacts HTML autonomes — diagrammes, galeries, decks, guides, présentations — à la charte Roxabi, compatibles file://, et déployables vers une URL en une commande. Pas de Figma, pas d'outil de slides, sans quitter le terminal.

01

Ce que c'est

Les modèles de langage écrivent beaucoup de mots. Parfois il te faut une image : un diagramme d'architecture, une comparaison côte à côte, un pitch deck, un guide à onglets, une page qui vit à une URL. roxabi-forge transforme « explique-moi ça » en un artefact HTML autonome que tu peux faire défiler, partager et livrer — déclenché depuis un skill, écrit dans un fichier, sans autre outil dans la boucle.

C'est un frère de roxabi-plugins : là où dev-core pilote le cycle de dev, forge pilote la sortie visuelle. Un pipeline HTML à la charte, indexé par manifest, pour les utilisateurs de Claude Code qui veulent des visuels de qualité publication sans quitter le terminal.

L'artefact est un seul fichier. Pas d'étape de build, pas de serveur, pas d'assets externes — ouvre-le n'importe où, y compris directement depuis le disque.

02

Huit skills

Chaque skill est une phrase déclencheuse qui produit un type d'artefact. Choisis la forme qui colle à ce que tu expliques.

SkillProduit
forge-chartUn diagramme natif mono-fichier — hub-and-spoke, gantt, ER, séquence, graphes de données.
forge-slidesUn deck scroll-snap de qualité magazine, navigué au clavier et au tactile.
forge-presentationUne présentation à défilement long — hero, sections numérotées, révélations.
forge-guideUn document multi-onglets en fichiers séparés — guide, architecture, récap.
forge-galleryUne galerie d'images ou d'audio indexée par manifest — pivot, filtre, lightbox.
forge-epicUne analyse liée à une issue — scope, graphe de dépendances, critères d'acceptation.
forge-mdRend du Markdown existant en HTML thémé — mono-fichier ou à onglets.
forge-initInitialise le runtime sous ~/.roxabi/forge/.
03

Autonome par conception

Trois propriétés tiennent à travers chaque skill. Ce sont elles qui font d'un artefact forge quelque chose que tu peux remettre à n'importe qui, n'importe où.

  • À la charte — les sorties portent les design tokens Roxabi par défaut ; type, couleur et espacement cohérents sans restyler chacune.
  • Autonome — CSS, scripts et données inlinés dans un seul fichier. Rien à héberger, rien qui casse plus tard.
  • Compatible file:// — chaque artefact s'ouvre directement depuis le disque dans un navigateur, aucun serveur requis pour le prévisualiser.

Les sorties atterrissent dans ~/.roxabi/forge/<project>/visuals/, indexées par un manifest pour que la galerie et le runtime puissent les retrouver et les grouper.

04

Livre-le vers une URL

Un artefact qui s'ouvre depuis le disque se publie tel quel. Une commande pousse l'arbre visuals/ vers Cloudflare Pages — le fichier même que tu as prévisualisé devient un lien à envoyer. L'instance Roxabi vit à forge.roxabi.com.

make forge deploy     # pousse visuals/ → Cloudflare Pages

Comme la sortie est statique et autonome, il n'y a aucun runtime à opérer — le déploiement est une copie de fichiers, et l'URL est juste l'endroit où le fichier vit désormais.

05

Lance-le

Forge s'installe comme plugin Claude Code depuis sa marketplace. Ajoute-le, installe, initialise le runtime une fois, puis déclenche un skill en décrivant ce que tu veux.

claude plugin marketplace add Roxabi/roxabi-forge
claude plugin install forge
"init forge"                              # mise en place du runtime, une fois
"draw the architecture of this repo"      # → forge-chart
"create deck from #42"                    # → forge-slides

Les skills, les templates et le runtime sont tous en accès ouvert.
